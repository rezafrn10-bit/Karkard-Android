# مخزن پروژهٔ مورخ — نسخهٔ ۰٫۷۳٫۰

این بسته، نسخهٔ تثبیت‌شدهٔ پروژهٔ اندروید مورخ است.

## فایل‌های مخزن

- `Karkard_Android_Project.zip` — آرشیو کامل سورس پروژه؛ نام این فایل برای گردش‌کارهای GitHub ثابت نگه داشته شده است.
- `.github/workflows/build.yml` — آزمون واحد، ساخت APK آزمایشی و آزمون دستگاهی روی Android API 29، 30، 34، 35 و 36.
- `.github/workflows/build-signed.yml` — ساخت APK امضاشده با Secretهای از قبل تعریف‌شدهٔ مخزن.

## اجرای ساخت و آزمون

۱. فایل `Karkard_Android_Project.zip` را در ریشهٔ مخزن GitHub با نسخهٔ جدید جایگزین کنید.
۲. دو فایل گردش‌کار داخل `.github/workflows/` را نیز با نسخه‌های همین بسته جایگزین کنید.
۳. در GitHub وارد زبانهٔ **Actions** شوید و گردش‌کار **Build and test VaghtNegar** را با **Run workflow** اجرا کنید.
۴. تنها وقتی همهٔ آزمون‌ها موفق شدند، از زبانهٔ **Actions** فایل APK آزمایشی را از بخش Artifacts دریافت کنید.
۵. برای APK امضاشده، گردش‌کار **Build Signed VaghtNegar Hoor APK** را جداگانه اجرا کنید. Secretهای امضا نباید در فایل‌های پروژه قرار گیرند.

## حفظ داده‌ها

نسخهٔ ۰٫۷۳٫۰ ساختار SQLite را تغییر نمی‌دهد و شمارهٔ schema همچنان ۲۲ است. برای نصب نسخهٔ امضاشده به‌عنوان به‌روزرسانی، باید کلید امضای قبلی مخزن حفظ شود.
