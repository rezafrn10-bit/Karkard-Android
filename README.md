# مخزن پروژهٔ مورخ — نسخهٔ ۰٫۷۴٫۰

نسخهٔ ۰٫۷۴٫۰ از سورس پایهٔ ۰٫۷۳٫۱ ساخته می‌شود و دو لایهٔ تغییر ثبت‌شده و قابل بازبینی را اعمال می‌کند:

- `.github/overlays/v074-core.patch` — اصلاح محاسبهٔ بازه‌های شناور نسخهٔ ۰٫۷۳٫۲، حفظ بازه‌های معتبر در روز ناقص، مهاجرت امن شیفت‌های قدیمی نسخه‌های ۰٫۴۳ تا ۰٫۶۲ به جدول مستقل فعالیت‌ها، آزمون‌های SQLite و ارتقای نسخه.
- `.github/overlays/daily-ui-flow.patch` — آزمون واقعی رابط ثبت ساعت، اسکرول دستی گزارش ماهانه و سیاست قطعی تعطیلات رسمی در ویرایشگر.

## نسخهٔ برنامه

- `versionName = 0.74.0`
- `versionCode = 76`؛ بالاتر از نسخهٔ ۰٫۷۳٫۲ با کد ۷۵، بنابراین امکان نصب به‌روزرسانی حفظ می‌شود.
- `minSdk = 26`، `targetSdk = 36`، `compileSdk = 37`
- نسخهٔ پایگاه داده: ۲۳

## ساخت و آزمون

- `.github/workflows/build.yml` آزمون‌های واحد، ساخت آزمایشی داخلی و آزمون Instrumentation واقعی روی Android API 34 را اجرا می‌کند. فایل Debug صرفاً برای اعتبارسنجی CI است و خروجی تحویلی کاربر نیست.
- `.github/workflows/build-signed.yml` پس از ورود تغییرات تأییدشده به شاخهٔ `main`، APK نوع **Release** را با کلید امضای خصوصی موجود در GitHub Secrets می‌سازد، امضا را با `apksigner` بررسی می‌کند و فایل امضاشده را به‌صورت Artifact منتشر می‌کند.
- برای نصب به‌عنوان به‌روزرسانی، کلید امضای قبلی باید بدون تغییر باقی بماند. هیچ کلید یا گذرواژه‌ای داخل سورس قرار نمی‌گیرد.

## حفاظت از ثبت ساعت و شیفت

موتور محاسبات چهار بازهٔ حضور و منطق ساعت ثابت/شناور نسخهٔ ۰٫۷۳٫۲ حفظ شده است. هنگام ارتقا از دیتابیس نسخهٔ ۱۷ (از جمله نصب‌های مبتنی بر نسخهٔ ۰٫۴۳)، شیفت معتبر ذخیره‌شده در ستون‌های قدیمی ابتدا به جدول `work_sessions` منتقل می‌شود؛ ستون قدیمی فقط پس از انتقال موفق همان رکورد پاک می‌شود. آزمون Instrumentation این مهاجرت را با SQLite واقعی و شیفت شبانه بررسی می‌کند.
